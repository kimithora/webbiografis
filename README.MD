# Web Biografis

Website biografis interaktif yang dikembangkan sebagai proyek mata kuliah **Pemrograman I**. Website ini menampilkan profil, perjalanan akademik, keterampilan, pengalaman, serta informasi personal dari dua mahasiswa dalam satu platform berbasis web.

## ✦ Design Concept

### Neo-Dada College Style

Landing page mengusung konsep **Neo-Dada College Style**, yaitu perpaduan estetika eksperimental Neo-Dada dengan elemen visual khas lingkungan akademik.

Karakteristik desain:
- Eksperimental dan ekspresif.
- Komposisi asimetris dan kolase visual.
- Tipografi berkarakter dengan hierarki dinamis.
- Elemen grafis bernuansa editorial dan akademik.
- Tampilan modern dengan sentuhan artistik.
