03 / THE TECHNOLOGY

Three tools.
One experience.

Tiga teknologi dasar yang bekerja bersama dalam membangun struktur, visual, dan interaksi website.

01

HTML5

THE STRUCTURE

Fondasi yang digunakan untuk menyusun struktur halaman, seperti judul, paragraf, gambar, tautan, formulir, dan berbagai elemen konten lainnya.

Pelajari HTML5 +

Apa itu HTML5?

HTML (HyperText Markup Language) adalah bahasa markup yang digunakan untuk menyusun dan memberikan makna pada konten halaman web.

Dalam proyek ini, HTML digunakan untuk membangun bagian navigasi, pengenalan mata kuliah, penjelasan teknologi, kartu biografi, dan pengaturan preferensi.

Contoh penerapan

  • Heading dan paragraf.
  • Gambar dan hyperlink.
  • Elemen semantik seperti header, main, section, dan footer.
  • Formulir dan elemen details serta summary.
02

CSS3

THE VISUAL

Teknologi yang mengatur presentasi visual website, mulai dari warna, tipografi, tata letak, jarak, dekorasi, hingga responsivitas tampilan.

Pelajari CSS3 +

Apa itu CSS?

CSS (Cascading Style Sheets) digunakan untuk mengatur bagaimana elemen HTML ditampilkan pada layar.

Pada proyek ini, CSS menerapkan pendekatan Simple Collage Art sebagai gaya utama, sekaligus memberikan identitas visual khusus pada masing-masing halaman biografi.

Contoh penerapan

  • Warna, font, dan tipografi.
  • Flexbox dan CSS Grid.
  • Responsive layout.
  • Transisi, animasi, dan efek visual.
03

JavaScript

THE INTERACTION

Teknologi yang memungkinkan website merespons tindakan pengguna, mengubah elemen halaman, serta menjalankan fitur interaktif.

Pelajari JavaScript +

Apa itu JavaScript?

JavaScript adalah bahasa pemrograman yang dapat digunakan untuk menambahkan perilaku dinamis dan interaktif pada halaman web.

Dalam proyek ini, JavaScript direncanakan untuk mengatur navigasi responsif, interaksi komponen, preferensi tampilan, serta pengaturan animasi.

Contoh penerapan

  • Menu navigasi responsif.
  • Carousel atau slider konten.
  • Pengaturan tema dan ukuran teks.
  • Pengelolaan preferensi pengguna.
i

Catatan: HTML, CSS, dan JavaScript memiliki fungsi yang berbeda, tetapi saling melengkapi. HTML menyusun konten, CSS mengatur tampilannya, sedangkan JavaScript mengatur perilaku interaktif yang diperlukan.

05 / THE ART DIRECTION

One website.
Multiple aesthetics.

ART DIRECTION 01 ■

Dark Bold
Brutalism.

Editorial modern bernuansa digital yang berani, eksperimental, geometris, dan ekspresif. Kontras tinggi serta aksen neon menegaskan karakter tanpa mengorbankan kenyamanan membaca.

Karakter & kesan

Bold, nyentrik, tegas, dan unik. Bentuk geometris, judul besar, serta elemen editorial menjadi penanda visual yang ekspresif.

Palet warna

  • #0B0B0B Hitam
  • #131313 Abu gelap
  • #1C1C1C Permukaan
  • #F4F1E8 Putih gading
  • #D4FF1A Neon lime
  • #FF3D71 Bright pink

Tipografi

Archivo Black untuk heading, Space Grotesk untuk isi, dan Space Mono untuk metadata. Judul serta label kapital membangun hierarki yang tegas.

Layout & komposisi

Editorial grid asimetris, ruang kosong yang seimbang dengan elemen padat, dan sidebar tetap di desktop. Nomor bagian, label kecil, serta dekorasi menjaga identitas di semua ukuran layar.

ART DIRECTION 02 ✳

Retro
Futuristik.

Antarmuka teknologi siber yang memadukan imajinasi masa depan, nuansa retro, dan atmosfer digital. Cahaya neon, garis geometris, serta gradien menjadi aksen pada pengalaman yang terstruktur dan modern.

Karakter & kesan

Futuristik, digital, neon, dan eksperimental; terasa seperti dashboard masa depan yang tetap mudah dipindai dan nyaman digunakan.

Palet warna

  • #0A0A0F Midnight black
  • #12121A Dark navy
  • #1A1A2E Deep indigo
  • #E8E8F0 Soft white
  • #A0A0B8 Abu-abu
  • #6A6A80 Muted gray
  • #00F0FF Neon cyan
  • #FF2D78 Neon pink
  • #A855F7 Neon purple
  • #F0FF00 Neon yellow
  • #FF6B35 Neon orange

Tipografi

Orbitron untuk heading, Rajdhani untuk isi, dan JetBrains Mono untuk metadata serta kode. Judul kapital dengan jarak huruf lebar memperkuat nuansa antarmuka digital.

Layout & komposisi

Header tetap dengan transparansi dan blur, konten terpusat dengan lebar maksimal, serta grid kartu untuk fokus keahlian dan informasi. Bagian profil menjadi pusat perhatian; tata letak tetap responsif. Cahaya neon dan gradien menonjolkan elemen penting.

Pengaturan tema global pada halaman utama dapat mengubah tampilan terang atau gelap tanpa menghilangkan identitas Dark Bold Brutalism pada halaman Kimi maupun Retro Futuristik pada halaman James.
